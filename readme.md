\# Smart Agriculture Monitoring System



A web-based agriculture monitoring system to track soil moisture, temperature, and humidity, and provide irrigation recommendations.



\## Features

\- User login and registration

\- Dashboard showing temperature, humidity, soil moisture

\- Irrigation alerts based on conditions

\- Recent sensor data display

\- Image upload for plant analysis



\## Tech Stack

\- Python (Flask)

\- MySQL

\- HTML, CSS, JavaScript

\- Chart.js

\- OpenCV



\## How to Run

1\. Install dependencies using requirements.txt

2\. Setup MySQL database

3\. Update database credentials in config.py

4\. Run app.py

5\. Open http://127.0.0.1:5000 in browser



\## Project Type

Academic project for smart farming and monitoring system
